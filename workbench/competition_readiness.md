## 平台文案草案

- 作品名称：**导师调查工作台**（未填团队、学校、指导教师信息）。
- 作品简介：**面向跨专业学生的本地导师调查工作台。用户先按姓名核对同名者身份，或按一级学科、高校、研究方向逐级选择导师；随后集中查看公开来源、论文候选与学术关系线索，按证据等级人工复核并导出调查记录。可导入自有资料，开源中文向量模型辅助研究兴趣检索。系统不对导师质量和师生关系自动下结论。**

## 提交前仍需完成

1. 以最终代码版本制作规则要求的 PDF 和 3–5 分钟演示视频；报告、视频、PPT 不写参赛学校、队名、成员、指导教师等身份信息。报告突出实际用户流程、公开资源清单、AI 模型/方法与基线比较，并如实写明样本限制。
2. 复查所提交的开源仓库 URL、许可证、第三方页面及模型引用，确定哪些原始数据可公开分发。当前本地代码变更尚未推送或发布，不能把本文件当作已开源证明。
3. 补充跨学校、跨专业的真实导师来源和独立标注的同名消歧/检索任务；若希望声称“提高效率”或“改善决策”，需真实用户任务数据。目前相关效果为未知。
4. 团队与报名信息、正式作品标题、平台上传结果均待用户确定和最终核对；本底稿不代表完成报名、提交或获得评审结果。

**两处分布倾斜已解决，值得在答辩中说明**：① **控制科学与工程**原先 149 条中华中科技大学独占 125 条（**84%**），跨校比较实际不成立；接入东北大学（123）、浙江大学（107）、东南大学（95）后为 **474 条 / 11 所**，最大单一机构占比降到 **26.4%**。② **石油与天然气工程**原先 164 条**全部来自中国石油大学（北京）一所**（100%）；接入中国石油大学（华东）221 位后为 **385 条 / 2 所**，单一机构占比降到 **42.6%**。这是"从堆数量转向修分布"的两个具体例子——**规模增长本身不是目的，可比较性才是**。

**如实披露的覆盖边界**：① 全国覆盖率**未评估**，46 个机构是抽样而非普查；② 仍有单机构学科：公安技术 14（1 所）、地质资源与地质工程 23（1 所）；③ **地质与公安技术本轮未做成**，原因是目标院校多次重试后仍不通、页面不列教师，或全国开设院校极少，详见 `workbench/README.md` 的「网络抖动与可达性判断」；④ 新增来源多数只覆盖学院下的**一个系或研究所**，每条记录备注里都写明了，不代表全校该学科师资；⑤ **方向的跨校可比性弱于机构数**：石油与天然气工程虽已两校，但两校名录都不含研究方向，其 385 条方向全为「方向待补」，跨校比较只能到姓名/院系/职称层面，**不能到方向层面**——不应被"机构数增加到 2"掩盖；⑥ 多数新增导师只有身份级信息，成果远未逐人补齐；⑦ 招生记录为 2024–2026 年历史目录，不代表当前名额。

**答辩要点（关系与参考分）**：与单纯的数据收纳项目相比，本作品的差异是**关系分析 + 学生向参考分**。关系四级分层中**只有 L1（27 条）有公开表述或学位指导记录支持，共同署名一律不推定为师承**；参考分只用学生一作占比、组内学生数下限、近三年产出、信息公开度四项公开信号，**不含论文数量、期刊档次、引用与头衔**。若被追问参考分的可信度，应说明：每个维度都显示依据与样本量，无证据的维度记为「无公开证据」并按剩余权重归一，且分数附「依据覆盖」比例。

**答辩注意事项**：本作品不主张"全"。若被问到覆盖，应直接承认是抽样并给出上表数字，同时说明设计取向是**来源可追溯 + 关系与参考分**而非追求覆盖规模；声称"覆盖全国"会被形式审查与复赛质疑。

**成果链接已可用**：仓库 `https://github.com/logic202407-cmyk/ic-mentor-db` 已于 2026-10-15 由私有改为公开，默认分支 `main`。已用无凭据方式核验：GitHub API 匿名查询返回 HTTP 200 且 `private=false`；匿名列目录 `/workbench` 与 `/workbench/aic-submission` 分别返回 38 与 7 个条目；匿名 `git clone --depth 1` 成功。评审无需账号即可访问。
