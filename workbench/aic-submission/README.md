## 一之二、上传前自检（一条命令）

```powershell
.venv\Scripts\python.exe -m workbench.tools.acceptance
```

它会依次跑完八道关卡并给出通过/失败清单：Python 测试、前端测试、公开前审计、
文档数字一致性、报告三件产物同步、来源红线、机构分布审计、**报告页数与大小**、
界面运行时冒烟（需先启动服务）。

**为什么要有这条命令**：这些检查原先分散在七个地方，靠临时脚本逐个跑，
本项目真实漏跑过两次——报告数字过期（写着"10,441 条"而实际已过万）、
主交付物 PDF 落后于 Markdown（md 已写 38/38，PDF 还是 35/3）。
**合成一条命令的价值不在省事，而在不会有遗漏。**

单独跑某一道：


## 六、重新生成 PDF

技术报告 PDF 由 Markdown 源文件生成。修改 `技术报告.md` 后重新生成：

```powershell
# 1. 统一中文引号（把直引号转成 “ ”，跳过代码块与行内代码）
.\.venv\Scripts\python.exe workbench\tools\normalize_cjk_quotes.py workbench\aic-submission\技术报告.md

# 2. Markdown → 带打印样式的 HTML（需要系统 Python 的 markdown 包）
py -3.12 workbench\tools\make_aic_html.py workbench\aic-submission\技术报告.md workbench\aic-submission\技术报告.html

# 3. HTML → PDF（使用系统自带的 Microsoft Edge 无头模式，无需额外安装）
.\workbench\tools\make_aic_pdf.ps1 -Html workbench\aic-submission\技术报告.html -Pdf workbench\aic-submission\技术报告.pdf
```

生成后请确认页数（应 ≤15）与文件大小（应 ≤10 MB）。
