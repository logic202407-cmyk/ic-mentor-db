## 七、合规结论

1. **许可兼容性**：所用组件均为 MIT / Apache-2.0 / BSD-3-Clause / MPL-2.0 / PSF 等宽松许可，与本项目以 MIT 开放代码、以 CC BY-NC-SA 4.0 开放数据的目标兼容，**不存在 copyleft 传染风险**（本项目未修改任何第三方源码，不触发对应源代码提供义务）。
2. **署名义务**：仓库根目录保留 `LICENSE`（MIT）与 `LICENSE-DATA`（CC BY-NC-SA 4.0）；本清单列明各组件名称、版本与许可；未删除或修改第三方源码中的许可头。
3. **再分发边界**：本项目**不打包再分发**第三方二进制组件与模型权重；用户通过 `requirements.txt` 自行安装，模型由用户端首次使用时从原始渠道下载。
4. **复合许可已披露**：NumPy 的 `BSD-3-Clause AND 0BSD AND MIT AND Zlib AND CC0-1.0`、pypdfium2 的随包依赖许可、tqdm 的 `MPL-2.0 AND MIT` 均已在本清单中单独标注。
5. **数据合规**：“公开可访问”不被视为当然的再分发授权。本项目对此的处理是只保存事实性信息与来源链接，不重新发布第三方网页全文，原始页面缓存不进入公开仓库。
6. **无访问凭据提交**：提交材料不含账号密码或 API 密钥。OpenAlex 的可选 API key 仅在本机进程环境变量中读取，不写入项目文件；仓库内无任何凭据（由公开前审计脚本自动校验）。
