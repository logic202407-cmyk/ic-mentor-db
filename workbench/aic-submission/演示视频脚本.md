# 演示视频脚本（3–5 分钟）

> 对应赛题要求：MP4，时长 3–5 分钟，300 MB 以内；须清晰展示**核心功能、操作流程、实现效果，以及开源项目改进或开放成果**。
>
> **匿名红线（务必遵守）**：视频中不得出现学校名称、学校 LOGO、指导教师信息、队名与成员姓名。录制前请关闭桌面通知，清空浏览器书签栏与标签页标题中的个人信息，浏览器窗口不要显示个人账号头像。

## 录制前准备（约 5 分钟）

```powershell
# 1. 启动工作台（仓库根目录）
.\.venv\Scripts\python.exe -m uvicorn workbench.app:app --host 127.0.0.1 --port 8765

# 2. 另开一个窗口，确认测试全绿（用于视频中展示验证环节）
.\.venv\Scripts\python.exe -m unittest discover -s workbench\tests
node --test workbench\tests\test_ui_races.cjs workbench\tests\test_research_ui.cjs
```

浏览器打开 `http://127.0.0.1:8765/`，**建议按 F11 全屏**，缩放调至 100%–125% 保证文字可读。

> **首次点击“AI 语义检索”会下载约 95 MB 模型文件**。请提前点一次让它下载完，避免正式录制时等待。

## 常见问题

**Q：可以用真实导师数据录制吗？**
可以，但**不建议**。真实数据涉及个人，且需再次核对隐私边界。合成演示资料（“载入跨专业合成演示”）10 条均为虚构，无权利争议，是更稳妥的选择。若必须用真实数据，请只展示已公开的来源链接与事实性信息，不得出现邮箱与联系方式。

**Q：语义检索第一次很慢怎么办？**
首次需要下载约 95 MB 模型并建立向量缓存。**正式录制前先跑一次**，之后再检索会命中本机缓存，响应在 0.1 秒内。

**Q：录屏时命令行出现本机用户名路径怎么办？**
把终端提示符切到仓库根目录的相对位置，或录制后用剪辑软件遮住路径。注意：仓库的公开前审计脚本本身会检查代码中不含硬编码本机路径，但**录屏画面**仍需自行确认。

**Q：没有配音条件？**
可以只录屏 + 加字幕。字幕请完整覆盖上表旁白要点，确保评审能理解“问题—方案—实现—效果—开放成果”的逻辑。
