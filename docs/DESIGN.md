# 界面设计系统（导师调查工作台）

这一版把界面从「文档式页面」改成了**产品门户 + 研究工作台 + 评测看板**三层结构。
样式只有两个来源：`workbench/web/assets/desk.css`（工作台与首页）与
`workbench/web/assets/eval.css`（评测页）。`desk.html` 不再内联样式。

## 1. 信息架构

| 视图 | 路由 | 说明 |
|:--|:--|:--|
| 首页门户 | `/` | 产品定位、两个真实入口、能力与流程、收录概览 |
| 研究工作台 | `/`（点「查找导师 / 按学科探索」后） | 左侧定位与筛选、右侧七分区档案；窄屏筛选改为抽屉 |
| 评测看板 | `/eval` | 摘要 KPI、检索/方向/消歧图表、失败案例、边界 |
| 经典整理视图 | `/classic` | 原资料整理页，保持不变，供兼容与对照 |

首页与工作台是同一份 DOM 的两个视图（`#homeView` / `#workspaceView`），
切换由 `setView()` 控制；工作台页头常驻「返回首页」链接，避免进入后找不到门户。

## 2. 颜色

| 变量 | 值 | 用途 |
|:--|:--|:--|
| `--bg` | `#F7F7F2` | 纸感底色 |
| `--surface` | `#FFFFFF` | 卡片与面板 |
| `--primary` | `#183C39` | 主按钮、标题、品牌 |
| `--accent` | `#527C70` | 链接、选中态 |
| `--sage` | `#84A49A` | 次级线条与状态点 |
| `--copper` | `#B6875A` | 少量强调（待复核、编号） |
| `--text` / `--muted` | `#263330` / `#697873` | 正文 / 辅助文字 |
| `--border` | `#E3E8E1` | 1px 分隔线 |
| 语义色 | `--ok` `--warn` `--unk` `--ai` | 三态与 AI 区块，**始终配文字，不单靠颜色** |

古铜色只用于「待复核」标签、章节编号与少量下划线，不允许大面积铺色。

## 3. 字体与字号

- 标题：`--font-serif`（Iowan Old Style → Noto Serif CJK → Songti），字距 `-.01em`。
- 正文与操作：`--font-sans`（Inter → PingFang SC → Noto Sans CJK → 微软雅黑），
  `body` 15.5px / 1.72；评测页 16px。
- 首页主标题 `clamp(40px, 4.6vw, 62px)`；页面标题 28–38px；模块标题 19–22px；
  辅助文字 12.5–13.5px。最小可用字号 11px，只用于编号与单位。

## 4. 组件

| 组件 | 规格 |
|:--|:--|
| 按钮 | 高 44px（首页主按钮 50px），圆角 10px；主色实心 / 浅底 / 幽灵三种 |
| 卡片 | 白底、1px `--border`、圆角 14–22px、阴影 `--shadow-sm`；悬停只换边框与阴影 |
| 分区导航 | 吸顶胶囊条；选中项白底投影；支持左右方向键 |
| 证据卡 | 标题 + 状态胶囊 + 摘要 + 页脚（原文链接 / 域名） |
| 观察卡 | 四维 2×2；三态徽标（● / ○ / ？ + 文字）；依据折叠 |
| 关系图 | 轻量 SVG 自我中心图；连线按 L1–L4 区分线型；可筛选层级；无证据不绘制 |
| 评测图表 | 手写条形与折线；每图配可展开数值表与 `aria-label` |

## 5. 动效

- 时长以 150–300ms 为主；`--speed: .22s`，`--ease: cubic-bezier(.22,.61,.36,1)`。
- 只做四类：视图淡入、卡片悬停、分区切换、图表/关系图出现。
- 全站支持 `prefers-reduced-motion: reduce`，关闭动画与平滑滚动。
- 不做视差、粒子、循环闪烁或大面积模糊。

## 6. 响应式

断点：1240 / 960 / 860 / 560。
- ≥1241：工作台 308px 侧栏 + 主内容；首页左右分栏。
- ≤860：侧栏折叠为抽屉（`#finderToggle`），打开导师后自动收起；首页隐藏预览卡。
- 移动端实测 `scrollWidth === innerWidth`（390×844），无页面级横向溢出；
  分区标签与评测章节导航只在自身容器内横向滚动。

## 7. 可访问性

- 全部表单控件有 `<label for>`；档案分区 `role=tab` / `aria-controls` / `aria-labelledby`
  与真实面板 id 一一对应。
- 状态不只靠颜色：三态徽标带字形与文字；证据状态写成「待人工核查 / 已人工核查」。
- 键盘：Tab / 方向键可用，`:focus-visible` 2px 描边；跳过导航链接常驻。
- 数据缺失一律显示「无公开证据 / 待产出」，不显示 0，不用占位假数字。
