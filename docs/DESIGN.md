# 界面设计系统（循证知途）

《循证知途》是一款专注于学术规范、证据可溯与中立客观的工学导师信息查询与调查辅助工具。本设计系统基于**蓝白学术风格（Academic Slate Blue System）**，借鉴开源交互项目 **ThreeUI** 的交互理念，打造兼具原创性、学术气质与成熟独立软件质感的交互体验。

样式由两个核心样式表构成：
- `workbench/web/assets/desk.css`：涵盖门户首页、导师检索工作台、学科导航、调查手记、数据来源与关于说明等六大核心视图。
- `workbench/web/assets/eval.css`：算法评测独立看板（真实指标对比、消歧与检索评测曲线）。

---

## 一、核心设计哲学与 ThreeUI 交互融合

我们坚持**“克制、精密、自然、以可读性为第一位”**的原则，坚决消除 AI 生成网页常见的“全屏死循环浮动、过度缩放弹跳、刺眼发光、廉价流动光边”等模板化表现：

| ThreeUI 核心理念 | 原理与特性 | 《循证知途》的具体落地与实现 |
|:---|:---|:---|
| **TactileButton** | 触觉式实体按压反馈：双层精细渐变边框、内嵌高光（`inset 0 1px 0 rgba(255,255,255,0.35)`）、分层深度投影（接触影 + 柔和漫反射环境影）、按压行程下沉（`translateY(1px) scale(0.985)`）。 | 应用于首页「开始检索导师」主按钮、工作台「搜索」按钮、档案 Tab 选项卡、调查记录保存操作与各类关键动作，带给用户坚实笃定的操作触感。 |
| **DotBorderButton & InterfaceLines** | 精密仪器与工程图纸秩序：1px 细线边界、两端平滑淡出渐变、边角精密定位微标记方块（Corner micro ticks）、轻量网格结构。 | 应用于首页 Bento 能力卡片边缘、四步工作流步骤框、导师搜索框聚焦态、学科卡片边框与激活导师卡片左侧指示条。 |
| **ConnectivityGraph** | 几何结构感与视线引导：严谨的拓扑秩序、细线连接关系、步骤间流向指示。 | 应用于首页「定位—核对—查阅证据—保存记录」工作流导轨，形成文档式自然展开的流水线认知；严禁用于生成虚构的人际关系或无证据导师图谱。 |
| **StreamConvergence (多流汇聚架构)** | 多流汇聚与证据核验概念：多源信息向中心客观核查。 | 展现在数据来源页面（`#sourcesView`）：纯净居中的多源汇聚架构图与客观核查原则卡片，直观传达高校官网、学院名录、学术数据库多源信息汇聚核验的准则。 |
| **PredictiveArc & SemanticBloom** | 局部动态组织与状态平滑过渡：从静止引导平稳过渡到结果状态，视觉锚点稳定，信息逐层落位。 | 应用于导师检索从“空状态”到“完整档案”的轻量淡入，档案模块（基本介绍、论文成果、招生信息、团队信息、公开来源）展开与收起时的自然高度过渡，杜绝科幻式文字重组或翻转。 |

## 二、六大核心视图架构

平台主体采用单页应用结构（通过 `setView()` 平滑调度）：

| 视图 | 对应 DOM | 核心定位与视觉呈现 |
|:---|:---|:---|
| **首页总览** | `#homeView` | 门户 Hero 学术大横幅（玻璃放大镜 GPT Image 2 艺术图，平稳落位）、能力 Bento 网格、四步调查工作流、收录统计与真实算法评测入口。 |
| **导师检索工作台** | `#workspaceView` | 核心调查工作区。双栏分层：左栏导师匹配列表（约 33%）、右栏五个可独立折叠的档案模块（约 67%）。默认只展开基本介绍；证据、核查状态和调查记录收进公开来源，帮助与热门方向按需展开。 |
| **工学学科导航** | `#disciplineNavView` | 教育部规范工学 38 个一级学科分类目录、代码即时筛选、晶体星轨插画。 |
| **本地调查手记** | `#recordsView` | 本地私密调查手记，数据 100% 留存在本机浏览器与本地存储中，不上传云端，保障调查隐私。 |
| **数据来源与核查** | `#sourcesView` | 数据来源规范、客观中立不排名声明、中心纯净居中的多源汇聚架构插画与客观核验准则。 |
| **关于说明** | `#aboutView` | 本地安全承诺、MIT 开源透明协议、3D 玻璃工作台图文平衡对仗。 |
| **算法评测独立看板** | `/eval` | 独立路由页面，提供检索效果、方向推断、同名消歧与真实评测用例的完整可复现看板。 |

## 四、动效治理原则与微交互

1. **安静稳重为主，彻底移除死循环浮动**：
   - 彻底停用六张 3D 插画原有的上下循环浮动动画（`subtleHeroFloat`、`subtleEmptyFloat`、`subtleDisciplineFloat`、`subtleRecordsFloat`、`subtleSourcesFloat`、`subtleAboutFloat`）。
   - 首页 Hero 主图仅在首次打开页面时执行一次柔和的落位进入动画（`heroAcademicSettle`，0.8s，从微沉到平稳落位），随后保持完全静止。
2. **轻量阻尼视差（Subtle Damping Parallax）**：
   - 基于 `requestAnimationFrame` 驱动线性插值阻尼缓动（Lerp Damping: 0.14）；
   - 严格限制最大倾斜角在 1.4°–2.2° 之内，移出容器平滑归正；
   - 页面隐藏（`document.hidden`）时自动暂停 RAF 循环，杜绝无意义的 CPU 消耗。
3. **消除廉价弹性弹跳（No Cheap Bounces）**：
   - 移除粗暴的 `visualBounce`；
   - 将主视觉微触动收敛为高保真 1px 机械行程微压（`visualTactileImpulse`）。
4. **尊重阅读体验**：
   - 导师姓名、机构名称、论文列表、来源链接和核验状态均保持绝对稳定，不进行任何动态模糊或文字重组。

## 五、无障碍合规与性能保障

- **减少动态模式（`prefers-reduced-motion: reduce`）**：
  - CSS 中所有动画（`animation`）与过渡（`transition`）均设为 `none !important`；
  - JavaScript 微视差引擎即时监测该媒体查询，直接跳过计算并清空任何 `transform`，保障敏感群体舒适阅读。
- **键盘导航**：
  - 核心操作控件、卡片均具备规范的 `tabindex="0"`、`role="button"` 或 `role="tab"`；
  - 全站具备清晰统一的 `:focus-visible` 2px 高对比度焦点环。
- **纯原生轻量实现**：
  - 零重型 WebGL 运行时依赖，完全由原生 CSS Transitions、Keyframes、SVG 与纯 JavaScript 控制，保证在低配置办公本与移动设备上均能稳定 60 FPS 运行。

## 六、响应式断点规范

严格保持经过技术加固的四个媒体查询断点：
- **> 1240px**：双栏宽幅工作台、首页 4 列 Bento 网格；
- **≤ 1240px**：双栏保持约 1:2，收紧间距，首页 Bento 网格转为 2 列；
- **≤ 960px**：工作台单栏堆叠，启用移动端返回搜索结果导航按钮；
- **≤ 860px**：桌面侧边栏隐入移动端抽屉，顶部搜索栏收拢；
- **320px–480px（移动端实测）**：通过 320×568、375×812、390×844 实机验证，无任何水平横向溢出，元素自适应排列。
