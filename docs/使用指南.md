# 使用指南

> 面向正在准备**保研（推免）/ 考研**、想要了解某位导师或某个方向的同学。
> 全文约 10 分钟读完；只想快速上手的话，看第一节就够了。

---

## 一、三分钟上手

### 1. 打开交互页面（无需安装任何软件）

下载仓库后，用浏览器**双击打开**下面任一文件即可：

| 文件 | 什么时候用 |
|:--|:--|
| `reports/导师推荐.html` | 已经大致知道自己想做什么方向 → **从这里开始** |
| `reports/导师库.html` | 想浏览全部 11 校 2114 位导师 → 用这个 |

> 两个文件都是**自包含单文件**，不联网也能用（数据已内嵌）。

### 2. 三步筛出候选

```
① 顶部「范围」下拉：集成电路设计与 AI 交叉 / 其他方向但在招（不选=全部）
② 「方向」下拉选一个方向（如"AI 芯片 / 加速器 / 体系结构"）
③ 「学校」下拉选目标学校（不选=全部）
④ 「招生」下拉选"主页明确在招"
```

结果就是**方向匹配 + 主页写了在招**的导师列表。

> **「范围」两类怎么选**：「集成电路设计与 AI 交叉」是数字/AI 芯片、体系结构、存算一体、模拟/电源、EDA、类脑、芯片安全等方向；
> 「其他方向但在招」是射频/毫米波、光电/硅光、MEMS/生医、器件/工艺、量子等方向中**主页明确写了招生**的导师。
> 如果你对某个方向不确定，建议先看"全部"。

### 3. 点开任意一行看详情

会展开：院系、课题组名、**主页链接**、**主页招生原话**（原文引用）、可引用的近期论文。
右下角有 **「✉️ 生成联系邮件草稿」** 按钮——点一下会自动填好这封信并复制到剪贴板，你只需替换 `[方括号]` 里的个人信息。

> 📧 **关于联系方式**：本项目**不收录任何邮箱**（隐私设计，见 [DISCLAIMER.md](../DISCLAIMER.md)）。
> 需要联系导师时，请通过详情里的**官方主页链接**自行获取联系方式。

## 三、指标怎么读（重要）

### 3.1 核心指标

| 指标 | 含义 | 怎么用 |
|:--|:--|:--|
| **综合分** | 8 维加权（产出强度 40% + 顶刊顶会密度 13% + 影响力 10% + 活跃度 10% + 署名伦理 8% + 头衔 8% + 团队 6% + 诚信 5%） | 横向比较同一方向的人 |
| **S（顶刊顶会）** | ISSCC / JSSC / VLSI Symposium / ISCA / MICRO / HPCA / ASPLOS / IEDM / Nature Electronics 的论文数 | **IC 领域最硬的指标**；S≥3 通常意味着组里有稳定的高水平工作与流片能力 |
| **A（一流）** | CICC / A-SSCC / RFIC / TCAS-I / TCAS-II / TVLSI / TCAD / TED / MTT / DAC / ICCAD 等 | 骨干产出，A 多说明组在持续产出 |
| **论文 / 近 3 年** | 可核实的 IC 相关论文总数 / 其中近三年数 | 近 3 年数明显偏低 → 可能已转行政、临近退休或方向变化 |
| **引用 / 篇均引用** | 总被引 / 篇均 | 篇均更能反映单篇影响力；注意新论文来不及积累引用 |
| **学生一作占比** | 论文中"第一作者为非本校教师"的比例 | **越高说明组内越习惯让学生挂一作**，对想攒一作的同学友好 |
| **组内学生(估)** | 去重后的学生一作人数 | 团队规模的**下限**估计，不是实际在读人数；大组资源多但要问清实际指导人 |
| **梯队 T0–T4** | 综合分分层 | 见下方"最大的坑" |
| **招生** | ✅在招 = 主页有明确招生表述 | 未标注 ≠ 不招 |

### 3.2 最大的坑：T3/T4 不代表导师水平低

**T4「公开证据不足」的典型成因**（都与水平无关）：

- 中文拼音**重名**（"张伟""刘洋""李鹏"这类名字，自动匹配极易失败）
- 英文署名与拼音不符（吕 → Lyu / Lu；复姓；用英文名发表）
- 研究以中文期刊、专利、工程型号为主，国际文献收录少
- 个人主页长期不更新，或院系网站信息不全

所以：**看到 T3/T4，先去点他的主页看**。页面上凡是标了 **⚠️ 疑似漏检** 或 **置信度=低** 的，基本都是这类情况。

### 3.3 另外三个要注意的点

- **顶会漏计**：Crossref 对 IEEE 会议论文的作者机构字段收录不完整，**实际顶会产出通常高于本库显示的数字**；
- **中文期刊未覆盖**：知网/万方的论文不在统计内，这对偏工程的老师影响较大；
- **指导质量完全没有**：导师是否 push、组会频率、补助多少、毕业去向、允不允许实习——**这些文献数据里没有**。

## 四、选导师六步法

### 第 1 步：定方向（比选人重要）

先问自己想做"**设计**"还是"**器件/工艺**"还是"**EDA**"：

- **模拟 / 混合信号 / 电源管理**：看 JSSC + ISSCC + CICC。这方向最看重**流片机会**，一定要问"一年流几次片、什么工艺"。
- **数字 IC / SoC / 体系结构 / AI 芯片**：看 ISSCC + ISCA/MICRO/HPCA + DAC。注意区分"**做芯片**"（有流片、有实测数据）和"**做架构仿真**"（只有仿真）。
- **存算一体 / 新型存储**：看 ISSCC + IEDM + TED，属器件-电路-架构交叉，出成果周期中等。
- **EDA**：看 DAC/ICCAD/TCAD，通常不需要流片，但需要较强的编程与算法能力。
- **器件 / 工艺**：看 IEDM + TED + EDL，实验依赖洁净室，**一篇论文 1–2 年是常态**，要能接受"慢"。

### 第 2 步：按梯队筛候选（用本库）

在 `导师推荐.html` 里按方向筛选 → 优先看 T0/T1 → T2 重点看方向匹配度与近 3 年活跃度 → T3/T4 一定要人工核实。

### 第 3 步：看"招生"列 + 打开课题组主页

优先联系 **✅ 主页明确在招** 的导师。报告里已把招生原话原文摘出，但**务必点开主页确认最新表述**。

### 第 4 步：查三类"文献里看不到"的信息（决定性）

1. **毕业去向**：近 3 年毕业的师兄师姐去了哪（海思 / 中兴 / 英伟达 / 高校 / 出国）——直接问在读学生，或看导师主页"毕业生"栏目；
2. **指导风格**：组会频率、是否 push、是否允许实习、毕业卡不卡、**补助多少**（上海/深圳/北京房租高，这条很实际）；
3. **一作与通讯惯例**：本库"学生一作占比"可作线索，但最终以组内实际惯例为准。

**找人的办法**：论文里的学生一作姓名 → 领英/GitHub/知乎/小红书搜索 → 礼貌私信询问（问事实，不问评价）。

### 第 5 步：发邮件（模板见报告第七节）

要点：
- 一次发 **3–5 位**，分批发，不要群发；
- 主题行写清「学校 + 姓名 + 方向」；
- 附 1 页简历 PDF + 成绩单；
- **引用对方一篇近期论文并说出你的理解**——这一条决定了回复率；
- 导师主页若写了具体要求（如"发送简历与研究兴趣简介"），**严格照做**。

### 第 6 步：面试前准备

- 把导师近 3 年的 3–5 篇代表作读完，能说出"这篇解决了什么问题、用了什么方法"；
- 准备好你自己项目的细节（为什么做、你负责什么、遇到什么问题、怎么解决）；
- 想清楚"为什么选这个方向、为什么选这个组"，以及 3 年后的打算。

## 五、常见问题（FAQ）

**Q1：我导师被分到 T4 / 信息不对，怎么办？**
提 Issue（用「信息更正 / 删除申请」模板）说明具体条目与官方页面链接，我们 7 个工作日内处理。**不需要提供任何证件**。

**Q2：为什么查不到某位老师？**
可能是：① 所在院系不在本次覆盖范围（见 README 各校覆盖说明）；② 研究方向不属于本库收录口径；③ 名字匹配失败。欢迎提 Issue 补充。

**Q3：数据多久更新一次？**
目前为一次性快照（截至 2026-09-24）。会按学期重建。你可以用 `tools/` 下的脚本自行重跑（见 README「复现」）。

**Q4：可以用它做商业产品吗？**
不可以。本项目采用 **非商业许可**（详见 `LICENSE-DATA`），且禁止批量联系名单中的教师。

**Q5：能加 XX 学校吗？**
欢迎。参考 `CONTRIBUTING.md`，新学校的成本主要是抓取师资名录 + 跑一遍 Crossref 富化（约 17 分钟/校）。

**Q6：我想自己复现一套。**
按 README 第五节的 10 步流程走即可，需要 Node.js 18+ 与 Python 3.10+，全程使用免费公开 API。

## 六、常用检索技巧

在页面搜索框里可以输入：

| 想找什么 | 输入示例 |
|:--|:--|
| 某个具体关键词 | `存算一体`、`RISC-V`、`ADC`、`Chiplet` |
| 某个课题组 | `智能计算`、`集成光电子`（会匹配院系与课题组名） |
| 某位老师 | 直接输姓名 |
| 某学院 | `集成电路学院`、`微电子学院` |

**排序技巧**：
- 找"最近很活跃的组" → 按**近三年**排序；
- 找"单篇影响力高的组" → 按**篇均引用**排序；
- 找"大组、资源多" → 按**组内学生数**排序；
- 找"愿意给学生一作" → 用报告里的「署名结构健康榜」。
