第一部分：现有 UI 视觉与素材实测深度分析
================================================================================

基于在 1920x1080、1440x900、1024x768 及移动端 390x844、320x568 真实 Edge 浏览器环境下的实际巡检与交互，对《循证知途》现有界面的视觉现状做出如下专业评估：

1. 整体色调与版式基调良好：
   - 界面整体贯彻了现代学术蓝（#1E60D5）、低饱和青蓝（#0284C7）、极浅蓝灰背景（#F4F7FB）与局部验证绿（#10B981）的色彩体系。
   - 布局采用了 Linear 与 Claude 风格的卡片式错层结构，文字信息排版严谨，层级分明，无横向溢出，响应式断点平滑。

2. 现有矢量图形素材的局限性：
   - 当前在 `workbench/web/assets/visuals/` 中的图片由脚本通过基础 SVG 矢量图形渲染转换而来（如简单的圆、矩形、虚线与渐变）。
   - 虽然结构完整且保持了透明通道，但在大屏（1440px 及 1920px）下，图形略显扁平化和“程序员几何拼凑感”，缺少精品数字产品（如 Apple 官网微距产品渲染、Linear 官网极简 3D 构件、Stripe 官网折射光泽）所具备的高级质感：
     a. 缺少真实的物理光影传递（Subsurface Scattering / 次表面散射）。
     b. 缺少磨砂亚克力与半透明水晶材质的柔和折射感（Frosted Glass Refraction）。
     c. 阴影较为机械，缺乏柔和的环境光遮蔽（Ambient Occlusion）。
     d. 知识网络线条偏硬，缺少如光纤微光般的灵动与空间纵深感。

3. 视觉重点不均与局部留白：
   - 首页 Hero 区域是平台建立第一信任感的核心屏障，目前右侧插画在 450px 宽度下视觉吸引力不足，需要一张真正具有艺术感染力的 3D 静态学术物料。
   - 数据来源页的现有图表类似简单的 UI 连线图，缺少“学术证据可溯源、坚不可摧”的厚重感与公信力。
   - 关于说明页左侧为多段文字，右侧留白偏大，需要立体感更强、光影通透的视觉主体实现视线平衡。

第四部分：统一的视觉母提示词（Master Visual Style Prompt）
================================================================================

为确保 GPT Image 2 生成的全部素材在色彩饱和度、光影走向、透视角度、材质质感上保持高度统一，建立如下母风格规范，后续所有图片的独立提示词均深度融合该母规范：

【艺术流派】
Modern Academic Clean Minimalist 3D Illustration / 精致现代学术极简轻量 3D 微距静物艺术。

【核心材质】
- 半透明磨砂亚克力 / 磨砂玻璃 (Frosted Glass / Acrylic with subtle blur & edge highlights)
- 高折射率纯净光学水晶 (Pure Optical Crystal Glass with clean caustic dispersion)
- 哑光哑白工程特种纸 (Matte Ceramic White Paper with delicate embossed texture)
- 细腻阳极氧化铝合金轻度金属构件 (Subtle Anodized Silver/Blue Metallic accents)

【光影体系】
- 45度柔和高位日光主光源 + 正面微弱冷白补光，无刺眼高光，无大面积浓黑死角阴影。
- 柔和的接触阴影（Soft Contact Shadows）与极其平滑的空气扩散光（Ambient Diffusion）。
- 局部点缀低亮度的内发光（Soft Internal Luminescence），透出学术科技蓝与鼠尾草绿的温润微光。

【色彩基准】
- 主题基调：学术深蓝 (#1E60D5) 与深海蓝 (#0F172A)
- 科技辅助：高光与折射采用冰川青蓝 (#0284C7 / #38BDF8)
- 校验点缀：低饱和验证绿 (#10B981)
- 衬底与基质：陶瓷白 (#FFFFFF) 与极浅冷灰 (#F1F5F9)

【透视与构图】
- 轻量等轴测视线（Isometric Perspective）或 15度浅微俯视微距透视，物体轮廓干净利落，具备空间漂浮层次感。
- 纯透明背景（Alpha Channel Transparent Background），边缘平滑羽化，杜绝脏边、硬黑边或自带实色底板。

【绝对负向规范】
No human figures, no faces, no portraits, no avatars, no commercial banners, no fake university logos, no readable dense text, no typos, no watermarks, no neon cyberpunk style, no noisy particle explosions, no dark gritty shadows.

第七部分：素材命名规范、透明通道处理与后续前端集成指南
================================================================================

1. 图片格式与命名规范：
   - GPT Image 2 生成交付时通常为 PNG 格式，统一命名为：
     `hero-academic-gpt2.png`
     `source-academic-gpt2.png`
     `search-empty-gpt2.png`
     `discipline-explore-gpt2.png`
     `about-academic-gpt2.png`
     `records-empty-gpt2.png`
   - 放置目录：统一保存在 `workbench/web/assets/visuals/`。

2. 透明通道（Alpha Channel）的保留与检查：
   - 交付前必须通过看图工具或脚本确认背景为真正的透明通道（即 Alpha 为 0），绝不能带有灰色棋盘格假透明背景，也不能带有纯白背景。
   - 若模型生成了带有纯白背景的图片，在后续集成阶段需使用高精度抠图算法平滑去除白色背景，保留亚克力边缘的自然过渡。

3. WebP 现代格式转换规范：
   - 在前端部署时，建议使用 Pillow 或 WebP 编码工具生成对应的 `.webp` 格式（如质量设为 92，启用透明无损压缩），以将 1MB~2MB 的大图压缩至 150KB~250KB，极大缩短首次加载时间。

4. 语义化 HTML 与无缝降级策略：
   - 保持现有 `<picture>` 标签结构：
     `<picture>`
       `<source srcset="/assets/visuals/hero-academic-gpt2.webp" type="image/webp">`
       `<source srcset="/assets/visuals/hero-academic-gpt2.png" type="image/png">`
       `<img src="/assets/visuals/hero-academic.svg" alt="" class="hero-art-img" width="450" height="280" loading="eager" decoding="async">`
     `</picture>`
   - 优势：首选 WebP 提速；若不支持则加载 PNG；若资源缺失则立即回退到现有的原生矢量 SVG，确保网站无论何时都不会出现破图或空白。
