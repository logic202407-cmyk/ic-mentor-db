# 集成电路 / AI 芯片 方向导师库（IC Mentor DB）

> **一个面向相关专业学生的开源信息整理项目**：把 11 所高校集成电路与 AI 芯片方向导师的
> 公开师资信息、公开学术产出与课题组招生信息汇总到一起，帮助大家在保研 / 考研时
> 对「梦校 · 梦组 · 梦导师」有一个更直观的了解。

> ⚠️ **请先阅读**：[免责声明与合规说明](DISCLAIMER.md) ｜ [使用指南](docs/使用指南.md)
>
> 本项目是**公开学术信息的整理与可视化**，其中的「综合分」与「梯队」**只反映公开文献计量证据的多少**，
> **不构成学术评价、人事评价或报考建议，也不对任何个人作出负面判断**。
> T3「公开证据较少」与 T4「公开证据不足」通常源于姓名重名、英文署名不一致或中文文献未覆盖等**数据原因**，
> **不代表导师水平或指导质量**。数据与文档采用 **CC BY-NC-SA 4.0（非商业性使用）**，
> **禁止将文中联系方式用于批量群发或其他骚扰行为**。

**覆盖**：清华大学 · 清华大学深圳国际研究生院 · 北京大学 · 复旦大学 · 上海交通大学 · 浙江大学 · 南京大学 · 中国科学技术大学 · 东南大学 · 西安电子科技大学 · 电子科技大学
**规模**：2114 位在职教师/导师（1660 位检索到可核实论文）｜顶刊顶会（S 级）1181 篇、一流期刊会议（A 级）3950 篇

## 🚀 快速开始（3 分钟）

1. **下载本仓库**（`Code` → `Download ZIP`，或 `git clone`）；
2. **双击打开** `reports/导师推荐.html`（用浏览器即可，无需安装任何东西、无需联网）；
3. 顶部依次选择 **方向 → 学校 → 招生状态**；
4. **点开任意一行**看详情（课题组、邮箱、主页招生原话、近期论文），
   点 **「✉️ 生成联系邮件草稿」** 可直接得到一封填好信息的邮件。

> 详细教程（指标怎么读、选导师六步法、FAQ、检索技巧）见 **[docs/使用指南.md](docs/使用指南.md)**。

## 📐 评分与分级口径

### 综合分（0–100，8 维加权）

| 维度 | 权重 | 口径 |
|:--|--:|:--|
| 产出强度 | 40% | S/A/B 级 venue 加权饱和分 |
| 顶刊顶会密度 | 13% | S 级论文 / 本人论文数 |
| 学术影响力 | 10% | 篇均引用（对数饱和） |
| 近期活跃度 | 10% | 近 3 年论文数 |
| 署名伦理健康 | 8% | 学生一作占比（越高越倾向把一作给学生） |
| 团队规模 | 6% | 组内学生数（估，去重一作中非本校在职教师者） |
| 头衔与平台 | 8% | 院士 / IEEE Fellow / 杰青 / 优青 / 教授分级 |
| 学术诚信 | 5% | Crossref 撤稿、更正核查 |

**S 级**＝ISSCC / JSSC / VLSI Symposium / ISCA / MICRO / HPCA / ASPLOS / IEDM / Nature Electronics
**A 级**＝CICC / A-SSCC / ESSCIRC / RFIC / TCAS-I / TCAS-II / TVLSI / TCAD / TED / MTT / TPEL / TC / DAC / ICCAD / FPGA / SSC-L / JLT

### 梯队（**仅反映公开文献计量证据的多少**）

| 梯队 | 名称 | 含义 |
|:--|:--|:--|

## ⚠️ 重要局限（请务必阅读）

1. **同名污染**：中文拼音重名严重，已做「姓名精确匹配 + 作者本人机构校验 + 非工科期刊剔除」三重过滤（全库剔除 1400+ 篇他人论文），仍可能有残留；标记"低置信""疑似漏检"的记录**请以官方主页为准**。
2. **T3/T4 不代表水平低**：常见成因是姓名重名、英文署名与拼音不符（吕 → Lyu/Lu）、研究以中文期刊与工程为主、主页长期未更新。
3. **顶会漏计**：Crossref 对 IEEE 会议论文（尤其 ISSCC/CICC）作者机构字段收录不完整，会**系统性低估**顶会产出；中文期刊（CNKI/万方）完全未覆盖。
4. **未做逐篇全文质量评分**：论文 PDF 绝大多数在订阅墙内，质量维度基于 venue 层级 + 引用 + 产出结构。
5. **招生信息有时效性**：主页表述可能滞后，以导师回复与院系最新通知为准。
6. **"组内学生数"是下限估计**：由论文一作去重推算，不等于实际在读人数。
7. **不含指导质量**：导师性格、组会风格、补助、毕业去向、是否允许实习等**文献数据里没有**，必须向在读/毕业学生核实。

## 🛠 复现与扩展

需要 Node.js ≥ 18 与 Python ≥ 3.10（`pip install pypinyin python-docx`）。

```bash
python tools/prepare_names.py            # 1. 中文姓名 → 英文变体（多音字异读组合）
node tools/enrich_crossref.mjs           # 2. 逐人 Crossref 检索（2114 人约 15 分钟）
node tools/score.mjs                     # 3. 指标计算 + 评分
python tools/skill_heuristics.py         # 4. 异常规则筛查（C01–C07）
node tools/integrity_check.mjs top260    # 5. 撤稿/更正核查
node tools/rank_final.mjs                # 6. 全库排名
node tools/fetch_labs_all.mjs            # 7. 抓取课题组主页
node tools/analyze_labs.mjs              # 8. 提取招生原话与联系方式
node tools/curate.mjs                    # 9. 构建方向推荐集
node tools/html_db.mjs && node tools/html_recommend.mjs   # 10. 生成交互页面
```

**想增加一所学校？** 见 [CONTRIBUTING.md](CONTRIBUTING.md) 第二节（含名录 JSON 结构模板与采集规范）。
