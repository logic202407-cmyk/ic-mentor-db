# 单一机构学科设点单位普查：0829 林业工程 / 0821 纺织科学与工程 / 0826 兵器科学与技术

- 普查日期：2026-10-23
- 探测方式：普通 GET（`requests`，Chrome/120 UA，(8, 25) 秒超时，失败重试 3 次，不执行 JS），`verify=False` 仅用于绕过部分院校证书链问题；HTTP 状态与页面结构逐页记录。
- 判据（唯一标准）：`max(原主导数, N) / (原总数 + N) < 0.60`；同时要求补入方自身不得成为新的独大，即 `N < 1.5 × 原总数`。
- 基线（`workbench/reference` 目录聚合后的实际计数）：0829 = 49 条（中国林业科学研究院）、0821 = 61 条（东华大学）、0826 = 104 条（军事科学院），三个学科都只有 1 所机构。

## 0. 结论（可直接写入技术报告）

1. **三个学科都不是"全国只有一所设点单位"。** 有公开依据的设点单位：0829 共 12 个（9 所高校 + 中国林业科学研究院 + 安徽农业大学、广西大学）、0821 共 11 个参评单位（另有南通大学可确认设点）、0826 共 11 个（第四轮 9 所 + 军事科学院 + 西安工业大学）。因此不能写成"全国几乎没有第二所"。
2. **真正的瓶颈是"公开师资名录的可达率"，不是"没有第二所"。** 本轮实测：0829 12 个单位里只有 3 所能拿到逐人名录（东北林业大学、中南林业科技大学有个人页，广西大学有表格名录但无个人页）；0821 11 个里只有 3 所能打开师资页（青岛大学、南通大学可逐人点开，四川大学是脚本壳页）；0826 11 个里只有 2 所能拿到带个人详情页的名录（北京理工大学、西安工业大学），另有 2 所（西北工业大学、中北大学）只能拿到纯文本名单。其余单位多数是 **TLS 握手被本机网络出口重置**，属于"本轮拿不到入口"，不能据此推断"该校没有师资页"。
3. **三个学科都已找到并实现可用来源，补后全部达标：**

| 学科 | 原主导 | 补入 N | 补后总量 | 最大机构占比 | 结论 |
|:--|--:|--:|--:|--:|:--|
| 0829 林业工程 | 49（中国林科院） | 61（东北林业大学） | 110 | 61/110 = **55.45%** | 达标 |
| 0821 纺织科学与工程 | 61（东华大学） | 57（青岛大学） | 118 | 61/118 = **51.69%** | 达标 |
| 0826 兵器科学与技术 | 104（军事科学院） | 139（北理工 124 + 西安工业 15） | 243 | 124/243 = **51.03%** | 达标 |

三个 N 都落在判据区间内（0829 [33, 73]、0821 [41, 91]、0826 [70, 155]）。

## 1. 判据与可行区间

`max(原主导数, N) / (原总数 + N) < 0.60`，其中 N 为补入量。

| 学科 | 原主导 | 原总数 | 下限 `原主导/(原总数+N)<0.6` | 上限 `N/(原总数+N)<0.6` | 本轮 N |
|:--|--:|--:|:--|:--|--:|
| 0829 林业工程 | 49 | 49 | N ≥ 33 | N ≤ 73 | 61 |
| 0821 纺织科学与工程 | 61 | 61 | N ≥ 41 | N ≤ 91 | 57 |
| 0826 兵器科学与技术 | 104 | 104 | N ≥ 70 | N ≤ 155 | 139 |

注：0826 的 N = 124（北理工）+ 15（西安工业大学）。按单机构口径 `max(104, 139)/243 = 139/243 = 57.20%` 也 < 60%；按机构分散口径最大机构为北理工 `124/243 = 51.03%`。0829、0821 两种口径结果相同。

## 7. 局限与写法建议

1. **清单口径**：第四轮学科评估只公布前 70%，本报告的三份清单是"两轮评估参评单位并集 + 已核实的硕士单位"，不是学位授权点全量。报告里应写"有公开依据的设点单位"，不要写"全国仅 N 所"。
2. **不可达 ≠ 无入口**：本轮大量 `*.edu.cn` 子站在本机网络出口被 TLS 重置（`SSLEOFError` / `RemoteDisconnected`），同一学校的主站或其他子站却可达（如东北林业大学材料学院可达、工程技术学院不可达）。这类单位应写成"本轮网络不可达"，不能写成"该校无师资页"。
3. **军事院校**：空军工程大学、火箭军工程大学、陆军工程大学、装备学院、海军工程大学没有公开的逐人师资名录（海军工程大学主页可达但无师资栏目），这类只能写"无公开名录"，不能写"无设点"。
4. **上限约束**：0829/0821/0826 的可用来源都超过本轮取用量；报告若被质疑"为什么只补这么多"，答案在判据上限 `N < 1.5 × 原总数`，不是来源不足。
