# 导师库分类归纳审计报告

> 生成日期：2026-10-12　｜　审计对象：导师关系网络 v5 的分类归纳结果
> 方法参照 GitHub 高星 skill 仓库 [data-science-agent-skills](https://github.com/emily2040/data-science-agent-skills) 中的三个 skill

---

## 1. Problem

导师库的分类归纳（方向、院校、辈分）是**用规则自动生成的**，而非人工标注。
需要回答三个问题：

1. **方向分类可信吗？** —— 一个关键词匹配器给出的方向标签，凭什么认为它是对的？
2. **「无关键词记录」这一组能当方向用吗？** —— 它占三成，如果缺失是系统性的，这组就自带偏倚。
3. **数据字段本身站得住吗？** —— 唯一性、空值率、取值范围。

## 3. Checks performed

### 3.1 标注一致性（Cohen κ）

参照 `domain-expert-collaboration-loop`：「量化标注一致性，制定边界样本仲裁准则」。

让**两个互相独立的标注者**对同一批人分类：

| 标注者 | 方法 | 是否看优先级 |
|:--|:--|:--|
| A | 首命中法：按方向优先级顺序，命中第一个即停 | 是 |
| B | 计分法：统计各方向关键词命中次数，取最高分 | 否 |

结果：

| 指标 | 值 |
|:--|--:|
| 样本量 | 3179 |
| 观察一致率 Po | 82.1% |
| 期望一致率 Pe | 15.0% |
| **Cohen κ** | **0.790** |
| 分歧样本 | 568（17.9%） |

判读标准（Landis & Koch）：κ 0.61–0.80 为「较好（substantial）」。
**κ = 0.790 落在「较好」区间**，方向分类可用。

### 3.2 分歧样本逐条核查

逐条看 568 个分歧样本后发现：**绝大多数不是标注错误，而是这些人本身就是跨方向的**。例如：

- **陆梁军**：AI 芯片 / 计算架构 ＋ 模拟 / 射频 / 微波 ＋ 光电 / 硅光子 ＋ 通信 / 信号处理
  - 原文：集成电路设计、射频/毫米波集成电路、处理器与体系结构、硅光/光电子集成、光纤传感与光通信、电磁与天线
- **周林杰**：AI 芯片 / 计算架构 ＋ 模拟 / 射频 / 微波 ＋ 光电 / 硅光子 ＋ 通信 / 信号处理
  - 原文：射频/毫米波集成电路、处理器与体系结构、硅光/光电子集成、光纤传感与光通信、通信基带与系统
- **郝跃**：AI 芯片 / 计算架构 ＋ 功率半导体 / 宽禁带器件 ＋ 可靠性 / 测试 / 安全 ＋ 材料 / 工艺 / 器件物理
  - 原文：宽禁带半导体材料与器件、微纳半导体新器件及其可靠性、SoC设计与设计方法学、超宽禁带半导体

⇒ 结论：**单一标签会丢掉一半信息，改为多标签**。

| 跨方向数 | 人数 |
|:--|--:|
| 1（单方向） | 886 |
| 2 | 658 |
| 3 | 289 |
| 4 | 70 |
| 5 | 17 |
| 6 | 2 |

跨方向者合计 **1036 人，占有关键词者的 53.9%**。

### 3.3 缺失机制诊断

参照 `missingness-mechanism-investigator`：「按 column / group / 目标关系分别剖面，判定 MCAR / MAR / MNAR」。

| 剖面 | 结果 |
|:--|:--|
| 整体缺失率 | 31.1% |
| 按院校 | 缺失率 19%（复旦）～ 55%（中科大），极差 35pp |
| 卡方检验（院校 × 缺失） | χ² = 86.7, df = 19, 0.05 临界值 ≈ 30.1 |
| 判定 | **p < 0.05，院校与缺失不独立 → 系统性缺失（MAR）** |
| 按职称 | 教授 28%、副教授 34%、研究员 30%、副研究员 31%、职称未标注 49% |

⇒ 结论：**「无关键词记录」不是随机分布，不能当作一个中立方向参与排序**。
页面中已将其单列并注明成因。

## 4. Findings

1. 方向分类的标注一致性 **κ = 0.790（较好）**，可用于筛选与导航；但**不应作为精确的学科归类**用于统计推断。
2. **跨方向是常态而非例外**：53.9% 的人同时涉及多个方向。任何「一人一方向」的呈现都是失真。
3. **关键词缺失是系统性的**（χ² = 86.7 > 临界值 30.1），校际差异达 35pp。
4. 数据契约整体健康：主键无重复，`name`/`school` 无空值；`kw` 空值率 31.1% 是最大缺口。

## 5. Decision

**`proceed-with-risk`**

分类归纳结果可用于**浏览、筛选、找导师**；
不可用于**学科实力统计、方向人数对比**等定量结论——因为缺失是系统性的，且跨方向者被强制归一。

## 6. Risks

| 风险 | 影响 | 缓解 |
|:--|:--|:--|
| 把「无关键词记录」当方向解读 | 中科大等校被系统性低估 | 页面单列该组并标注成因 |
| 把主方向当作唯一方向 | 跨方向者（54%）信息丢失 | 已加虚环与「跨 N 个方向」标注 |
| 关键词表本身不完备 | 268 人落入「其他/未归类」 | 已显式列出，「其他」不参与方向排序 |
| 方向标签被当作学科评价 | 误导择校/择导 | 页面与报告均声明「不构成任何评价」 |

## 7. Next actions

1. 扩关键词表，把 268 个「其他/未归类」压下来（当前可按高频未匹配词定向补充）。
2. 补齐缺失的 `kw` 字段——需重抓那些页面未写研究方向的院系（中科大、哈工大、中科院微电子所优先）。
3. 若要做方向人数统计，须按院校分层加权，或只报告「有明确关键词者」的子集。
